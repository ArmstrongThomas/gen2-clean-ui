# Pokédex redesign concepts

These are design-only concept boards for the Gen2 Pokédex redesign. They are
not runtime assets and do not change the current mod implementation.

Each SVG contains three companion screens:

1. Index/list
2. Pokémon details
3. Habitat/area

The additional data-page board adds:

4. Evolution chain
5. Level-up moves
6. TM/HM compatibility

## Concept directions

### 01 — Slate Index

The safest evolution of the current UI. It keeps the list-first workflow, but
gives the selected Pokémon a stronger identity card and makes the page tabs
explicit instead of hiding them in action text.

### 02 — Field Guide

A more editorial, card-based layout. The selected Pokémon is the primary
subject, with the index reduced to a compact navigation rail. Details are
organized into short, scannable groups rather than a long row list.

### 03 — Habitat Atlas

A navigation-first concept for exploration. The index and habitat pages share a
map/region language, while details remain deliberately compact. This direction
is best if “where can I find it?” becomes a first-class Pokédex task.

The concepts intentionally avoid committing to exact copy, final sprite scale,
or a specific palette. They are meant to establish hierarchy, navigation, and
information density before implementation.
