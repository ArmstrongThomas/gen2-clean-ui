This is the Gen2 Clean UI 0.4.0 release. It begins the visual
redesign of the Pokédex while preserving the drop-in compatibility boundary
with `gen1recomp`.

## Pokédex redesign

- Added the Cartridge Pages / Field Guide visual direction and compatibility
  plan.
- Redesigned the reachable Info presentation with clearer `INFO` labeling,
  species metadata, type badges, status, and entry-page hierarchy.
- Redesigned the reachable Habitat presentation with map-backed landmark
  markers, region metadata, and route-list fallback when map data is
  incomplete.
- Added detached, function-free reference snapshots for:
  - evolution targets and requirements;
  - level-up moves and move metadata;
  - TM/HM compatibility and move metadata.
- Added deterministic fixture coverage for the new reference data and
  map-backed Habitat presentation.

## Compatibility boundaries

- The host repository remains read-only and unchanged.
- Native Pokédex navigation remains source-owned.
- Evolution, level-up move, and TM/HM pages are model-ready but are not yet
  claimed as live pages.
- Additional mod-owned navigation seams will be implemented only after the
  visual redesign of the reachable pages is complete.

## Verification

The Linux test suite passes, including syntax, contract, Gallery, responsive,
and Pokédex Pack/Dex/Trainer/Save coverage.
