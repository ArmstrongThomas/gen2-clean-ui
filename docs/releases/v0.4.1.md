This is the Gen2 Clean UI 0.4.1 release. It continues the Pokédex visual
redesign with the shared V3 document presentation contract and preserves the
drop-in compatibility boundary with `gen1recomp`.

## Pokédex and document presentation

- Synced the Gen2 package with the merged Clean UI Core document contract.
- Restored document layout, rendering, metadata, tabs, grid regions, and sprite
  presentation for the Pokédex screens.
- Preserved active Pokédex entry-page selection and native action state.
- Added the shared Core assets required by the Gen2 presentation fallback.

## Compatibility and verification

- The host repository remains read-only and unchanged.
- Native Pokédex navigation remains source-owned.
- The Core vendor lock now covers every synchronized file and verifies matching
  hashes and sizes.
- The complete Linux test suite passes, including syntax, contract, Gallery,
  responsive, and Pokédex Pack/Dex/Trainer/Save coverage.
