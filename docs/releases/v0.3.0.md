This is the next Gen2 Clean UI development release after the completed 0.2.0
package. It carries follow-up polish and compatibility work while the battle
and Pokegear-family replacements remain explicitly deferred/native.

The shared Clean UI settings now expose Clean, Red, Blue, Yellow, Gold,
Silver, Crystal, and High Contrast palettes in that order, followed by a
Dark Mode toggle. Dark Mode selects the matching dark/light variant for each
palette, including Light High Contrast and the Clean/Dark neutral pair. The
palettes are registered in shared Core with readable text/paper contrast, and
the Mod Menus page follows the persisted selection on released hosts.

Font sizing is now family-relative: OpenTTD Mono is the default 10px 1x face,
while Plain Pixel and System retain their 15px 1x bases. The public choices are
AUTO/1x/2x/3x; explicit 4x remains an internal authored-style step. The shared
solver probes required text for the shell and every detached V3 presentation
family, then selects the next lower authored step when the requested one would
truncate or overlap content. Required text is never hidden behind an ellipsis.

The 0.3.0 line does not reactivate the deferred battle architecture or the
Pokegear-family replacement. The official host remains authoritative for
battle, phone, map, Fly, clock, and radio presentation until those surfaces
receive a separate redesign.

Gen2-first Party/Summary work also begins in this line. The detached Clean UI
model now carries the six party rows, animated icon crops, the supplied gender
sheet, level/HP data, empty
healthy status state, abnormal three-character status codes, distinct one/two-
type badges, and source-ordered JOURNAL / MOVES / DETAILS tab geometry. Core
also supplies non-stretched PlainPixel hierarchy styles and structured summary
field cards. Core-owned raster layers now use nearest-neighbor filtering,
integer-aligned output bounds, and whole-pixel/reciprocal scaling to avoid
mixels; gender assets follow the selected font's pixel height without forcing a
fractional source scale. The visual slice is covered by deterministic model,
layout, and image-path tests. The released V3 host still owns controller
dispatch, so live tab/move navigation, icon cadence, and multi-window-size
appearance remain user-test requirements.
